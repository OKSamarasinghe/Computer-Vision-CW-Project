# Report

Final PDF report (max 20 pages) goes here, e.g. `DR_Coursework_Report.pdf`, plus its source file
(`.docx`) if you're drafting in Word.

Structure (per the coursework brief): steps taken → what was innovated → tools/technologies/datasets
used → justification for every choice. Your existing `Report_Section_Criterion*.md` files (from the
Claude Project) map directly onto this — Criterion 1 → dataset justification, Criterion 2 →
preprocessing, Criterion 3 → augmentation, Criterion 4 → architecture, Criterion 5 → training
strategy, Criterion 6 → evaluation. Add a Criterion 9 section using `../docs/innovation_design_notes.md`
as source material.

Required:
- Architecture diagram + pipeline diagram (`diagrams/`)
- Codebase/output screenshots (`screenshots/`)
- Charts: loss/accuracy curves, class distribution, confusion matrix (pull from `../kaggle_artifacts/`)
- References in Harvard APA 7th, in-text citations from 2022 and above (`references/`)
- The hosted video demo URL, embedded in the report text
